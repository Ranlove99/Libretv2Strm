# 示例源清单

两份可直接导入的文件，配合「设置 → 点播源 / 直播源 → 从文件导入」使用。

| 文件 | 类型 | 条数 |
| --- | --- | --- |
| `vod-sources.json` | 点播源（Apple CMS 采集站） | 22 |
| `live-sources.json` | 直播源（M3U 列表地址） | 24 |

地址均为第三方公开接口，**本仓库不控制、不背书、不保证长期可用**。2026-11-21 实测可拉取，之后随时可能失效——导入后建议先跑一次「批量测活」，再决定启用哪些。

## 点播源说明

22 个采集站按验证方式分两类：

- **搜索可用**（直接 `ac=videolist&wd=关键词` 返回结果）：暴风、量子、最大、虎牙、极速、魔都、电影天堂、360、iQIYI、百度、猫眼、红牛、ikun、无尽、速博、新浪
- **仅列表可用**（搜索功能被源站关闭，`ac=list` 正常返回分类和视频列表，可采集不可搜索）：U酷、奥斯卡、牛牛、丫丫、索尼、闪电

## 直播源说明

24 个 M3U 列表覆盖以下类别：

- **央卫视 / 地方台**：vbskycn IPv4、Kimentanm aptv、YueChan 北京联通（含节目单）、范明明 IPv6
- **综合集合**：YanG 集合源、zbefine、ChinaIPTV 自动更新、BigBigGrandG、epg.pw 大陆
- **iptv-org 分类专题**：全球汇总、电影、新闻、体育、纪录、娱乐、儿童、音乐
- **iptv-org 国家/地区**：中国、美国、英国、日本、韩国、中国香港、中国台湾

## 点播源格式

```json
{
  "name": "我的点播源",
  "sources": [
    { "name": "示例采集站", "url": "https://example.com/api.php/provide/vod" }
  ]
}
```

`url` 必须是 Apple CMS 的 `api.php/provide/vod` 接口。可选字段：

- `detail` — 详情页根地址（少数源需要爬详情页取 m3u8）
- `isAdult` — 标记成人内容，配合「过滤成人内容」开关

也接受以下等价形态（导入时自动识别）：

- 裸数组 `[{ "name": "...", "url": "..." }]`
- 接口目录 `[{ "name": "...", "baseUrl": "..." }]`
- TVBOX 多源配置 `{ "sites": [{ "name": "...", "type": 1, "api": "..." }] }`（Spider 类站点自动跳过）

## 直播源格式

```json
{
  "name": "我的直播源",
  "liveSources": [
    { "name": "示例列表", "url": "https://example.com/iptv.m3u" },
    { "name": "带节目单", "url": "https://example.com/cn.m3u", "epg": "https://example.com/epg.xml" }
  ]
}
```

`url` 指向 **M3U 列表地址**，不是频道播放地址。可选 `epg` 为 XMLTV 节目单地址。

在直播面板里，裸数组 `[{ "name": "...", "url": "..." }]` 一律按直播源解释（点播面板里同样的数组按采集站解释）。

## 关于 M3U 频道文件

本地 `.m3u` 频道播放列表不能直接导入——本应用的直播源模型是「一个可拉取的列表地址」，频道在播放时才解析。要导入自己的 m3u，把它放到任意 HTTP 服务上，然后用那个地址添加直播源。
